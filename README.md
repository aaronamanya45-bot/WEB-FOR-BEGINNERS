# Student Management Database
A beginner-friendly SQL database project for an IT/Database coursework portfolio.
## Contents
- `student_management_database.sql` - complete database creation, sample data, and practice queries.
## Database Tables
- Departments
- Courses
- Students
- Lecturers
- Enrollments
- Results

## SQL Concepts Demonstrated
- CREATE DATABASE
- CREATE TABLE
- Primary keys
- Foreign keys
- INSERT
- SELECT
- WHERE
- UPDATE
- DELETE
- JOIN
- COUNT
- MAX
- MIN
- AVG
- ORDER BY

## How to Use
Open `student_management_database.sql` in MySQL, MySQL Workbench, phpMyAdmin, or another compatible SQL environment and run the statements.
